# Delegation

This layer is the native home of bounded delegation and subagent governance for
the helm platform (Z.ai).

Native authority now starts here:

- `subagent-model.md`

Supporting inherited doctrine may still exist in `references/`, but delegation
should no longer depend primarily on imported modules.

> **Z.ai Note:** No Z.ai, a delegação é realizada via Task tool com 5 subagent types:
> `full-stack-developer`, `Plan`, `frontend-styling-expert`, `Explore`, `general-purpose`.
> Veja `subagent-model.md` para o mapeamento completo de personas → subagentes.
