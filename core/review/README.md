# Review

This layer is the native core home of review architecture for the standalone
`helm` platform.

Use it when review shape, review depth, review-of-review, or forensic
reconciliation must be explicit.

Native authority now starts here:

- `product-critical-surfaces.md`
- `premium-interface-production.md`

Supporting inherited doctrine may still exist in `references/`, but review
method should no longer be implicit or left primarily to imported modules.
