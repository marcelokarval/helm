# Core

This directory is the long-term home of the non-negotiable laws of the
`helm` platform for Z.ai.

The core owns:

- root orchestration
- skill activation (via Skill tool)
- prompt hardening
- issue topology (via docs/TASKS.md)
- bounded delegation (via Task tool subagentes)
- lane governance
- risk enforcement
- review architecture
- workflow catalog and calibration
- root closure mode
- runtime packet contracts
